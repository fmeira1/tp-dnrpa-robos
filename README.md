# Scoring de riesgo de robo vehicular

App del TP de Modelizado de Sistemas e IA (Grupo N° 3), con datos abiertos de la DNRPA.

## Ejecutar localmente
```
pip install -r requirements.txt
streamlit run app_dnrpa.py
```

`dataset_limpio.csv` y `modelo_scoring_recupero.joblib` ya vienen generados por `tp_dnrpa.py`,
así que la app arranca directo sin descargar ni reentrenar nada.
